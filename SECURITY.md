# Security

Only the latest release is maintained. This community project has no guaranteed response time.

Use [private vulnerability reporting](https://github.com/ahmed-progra/sapphire-windows/security/advisories/new). Include affected versions, reproduction steps, impact, and a safe proof of concept. Do not include real credentials/user data or open a public issue for an unpatched vulnerability.

The renderer is sandboxed, native commands are allowlisted, and the helper runs without elevation. These controls do not replace security review. Ordinary notes, clipboard history, and backups are unencrypted; see [privacy](docs/PRIVACY.md).

Release binaries are unsigned. Download from this repository's Releases page and verify SHA-256 checksums. Checksums detect mismatch; they are not a signing identity.
